# KonBilge
konbilge.deb kurulum dosyasının md5sum=74383141b483d7bdec829181189fde59
Türkçe'den Braille(Kabartma) Çeviri Programı.
Programın exe uzantılı kurulum dosyası, açıklaması,videosu https://konya.meb.gov.tr/www/konbilge-kabartma-ceviri-programi/icerik/2203
adresinde yer almaktadır.
Okulların pardus kurulu akıllı tahtaları içinde uyumlu olan, Pardus için kurulum dosyası Konbilge.deb indirerek kurulumu gerçekleştirebilirsiniz.
Geliştiriciler için Konbilge klasörünü indirip Netbeans'a proje olarak File menüsü open project ile açmaları yeterli olacaktır.
Bütün pardus sürümleri için çalışabilmesi için Oracle OpenJDK 17.0.2+8 seçilmiştir.
Kendi oluşturduğumuz Kabartma.ttf fontu font klasöründedir.
Harici kullanılan kütüphaneler dist-lib klasöründedir.
